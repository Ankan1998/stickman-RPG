# Stickman RPG — Audio Pack v1.0.0

**62 sounds × 3 variants = 186 files**, in both WAV and OGG.
Chunky-retro style to sit with the pixel art: synthesized, bit-crushed a little, a whisper of
stone-room reverb, short tails.

Like the art, every sound is **generated by the Python in `tools/`** — no recorded samples.
A slash is "a noise burst swept through a bandpass with this envelope", so retuning the whole
pack is a constant change and a re-run:

```bash
pip install numpy scipy          # ffmpeg is needed for the OGG step
python tools/build_audio.py out/
```

## Layout

```
combat/   16 impacts       slash_light_1.wav  slash_light_2.wav  slash_light_3.wav  (+ .ogg)
voices/   16 hurt/death    human_hurt_1.wav … golem_death_3.wav
magic/    12 effects       fire_1.wav … smoke_3.wav — one per fx_*.png in the art pack
ui/       18 menu+dungeon  ui_move_1.wav … gold_pickup_3.wav
manifest.json              every file with duration, peak, RMS, and which sprite it pairs with
tools/                     the generators
```

Both formats are mono, 44.1 kHz. WAV is 16-bit PCM (10.7 MB total);
OGG is Vorbis q5 (2.0 MB total). Godot plays either — use OGG for
anything longer than a blip, WAV for the menu sounds where decode latency matters.

## Variants

Every sound has three takes. They differ in the same ways real takes do — a little pitch,
a little length, a little level — so a mace landing three times in a row does not sound like
a machine gun. Pick one at random on each play:

```csharp
// Godot C#
var take = GD.RandRange(1, 3);
GetNode<AudioStreamPlayer>("Sfx").Stream = GD.Load<AudioStream>($"res://audio/combat/blunt_hit_{take}.ogg");
```

All files are normalised to the same peak (−1 dBFS) with the loud layers first, so the mix
balance between them is roughly right out of the box; `suggested_volume_db` in the manifest is
where to record per-sound trims once you have music under them.

## Which sound goes with which sprite

| Hero / enemy action | Sound | Sprite frame to trigger on |
|---|---|---|
| Sword, katana, dagger attack lands | `slash_light` + target's `hit_*` | attack frame 3 (the strike) |
| Greatsword, axe, scythe attack lands | `slash_heavy` + target's `hit_*` | attack frame 3 |
| Mace, club, hammer attack lands | `blunt_hit` / `blunt_heavy` | attack frame 3 |
| Spear, trident, arrow, bolt lands | `pierce` | attack frame 3 (or on projectile hit) |
| Bow / crossbow fires | `bow_release` / `crossbow_release` | attack frame 2 (the loose) |
| Claw or monk attack | `claw_hit` | attack frame 3 |
| Any attack misses | `miss_whoosh` | attack frame 3 |
| Critical hit | `critical_hit` (instead of the normal hit) | attack frame 3 |
| Shield user blocks | `shield_block` | hurt frame 0 |
| Parry | `parry_clang` | hurt frame 0 |
| Caster winds up | `spell_cast` | attack frame 1 |
| Spell lands | `magic/<effect>` matching `fx_<effect>.png` | first frame of the effect |
| Character takes damage | `voices/<family>_hurt` | hurt frame 0 |
| Character dies | `voices/<family>_death` | death frame 1 |

## How the voices work

A creature voice is a glottal pulse train pitched by a contour, pushed through resonators at
vowel formant frequencies (`a`, `o`, `u`…) with breath noise mixed in. Change the pitch, the
formant scale and the roughness and the same engine gives you a goblin (330 Hz, formants
scaled up 25%, fast jitter), a beast (100 Hz, 26 Hz amplitude flutter — the growl) or a demon
(80 Hz, a sub-octave, heavy drive). Skeletons, slimes and golems have no larynx, so they are
bone knocks, water and stone instead.
